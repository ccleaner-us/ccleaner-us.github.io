# CCleaner Guides — Part 1 of 8 (100 articles)

This is a standalone GitHub Pages site containing 100 HTML articles.

Files: index.html, style.css, support.html, .nojekyll, articles/ (100 pages).

Upload the contents (not the ZIP) to the ROOT of a GitHub Pages repository. In Settings > Pages select Deploy from a branch, main, /(root).

IMPORTANT: Each pack has its own index.html and overlapping filenames for site infrastructure. To publish all 800 on ONE GitHub Pages site, merge article folders and regenerate a single combined index. Do not overwrite index.html expecting all 800 to appear.

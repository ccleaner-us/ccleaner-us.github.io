# CCleaner Guides — 100 articles for GitHub Pages

Contents: index.html, style.css, support.html, articles/ (100 HTML articles), .nojekyll.

## Publish
1. Create a GitHub repository, or open your existing GitHub Pages repository.
2. Upload the CONTENTS of this ZIP to the repository root (not the ZIP itself).
3. Commit the files to the main branch.
4. Open Settings > Pages > Build and deployment, select Deploy from a branch, main, /(root), then Save.
5. Wait for the deployment and open the Pages URL shown in GitHub.

The site uses relative links, so it works for both username.github.io and project repository GitHub Pages URLs.

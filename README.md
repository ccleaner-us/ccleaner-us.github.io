# CCleaner Guides — GitHub Pages

Upload the homepage ZIP contents to the root of one GitHub repository. Extract each of the eight article ZIPs and upload their `articles/` directories to that same repository, merging rather than replacing the folder. Each ZIP contains 100 unique HTML pages. The index page intentionally shows only the title and Home / Support menu; it does not list article links. Article URLs are `/articles/<filename>.html`.

The site is independent and not affiliated with CCleaner. Links on buttons are third-party destinations, not verified official vendor websites. Review them carefully before publishing.

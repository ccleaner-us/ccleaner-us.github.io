# CCleaner GitHub Pages — 800 articles

Upload the contents of CCleaner_Homepage_800_GitHub.zip to the repository ROOT. Then extract and upload each of the eight CCleaner_Articles_100_Part_XX.zip files to the SAME repository ROOT. Keep the `articles/` directory path intact; GitHub will merge files into that directory. Do not upload ZIP files themselves as the published site.

The homepage has 800 links and works after all eight article packs are uploaded. Set Settings > Pages > Deploy from a branch > main > /(root).

For project repositories, relative URLs work under /repository-name/. For username.github.io repositories, they work at the domain root.

Independent informational site; review content and third-party links before publishing.
